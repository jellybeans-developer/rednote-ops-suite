# Contributing

Contributions are welcome. By participating, you agree not to add credential scraping, private API reverse engineering, CAPTCHA bypass, anti-detection logic, engagement manipulation, or silent publishing.

1. Open an issue describing the change and its safety implications.
2. Create a focused branch and add tests.
3. Run `npm run check`.
4. Do not commit `.env`, `.rednote-ops`, real account data, or access tokens.
5. Submit a pull request using the template.

Official platform adapters must link to the applicable official documentation, declare required scopes, keep secrets server-side, and preserve the human approval gate.
