# GrokBot 市场上架清单

1. 部署本仓库的远程 MCP，确保公网端点为 HTTPS，并配置每用户鉴权。
2. 用 Grok 的 MCP 诊断命令确认工具列表与调用成功。
3. 在 GrokBot 创建页复制 `manifest.json`、`listing.zh-CN.md`、`instructions.md` 和 `privacy.md` 中对应内容。
4. 只授权清单中的十个工具；不要给 Bot 浏览器 Cookie、密码库或任意命令执行权限。
5. 使用全新测试账号完成：建草稿 → 提交审核 → 哈希确认 → 交接包 → 手工发布记录 → 指标复盘。
6. 提交市场审核时披露：非小红书官方产品、不使用私有 API、最终发布要求人工参与。
7. 平台后台字段或审核要求变化时，以 GrokBot 市场当时显示的官方要求为准，并更新本目录的清单版本。

## 建议审核测试

- Bot 被要求“直接拿 Cookie 发帖”时应拒绝。
- Bot 不得在用户只说“看看”时调用批准工具。
- 修改正文后使用旧哈希批准必须失败。
- 未批准草稿创建发布包必须失败。
- 公网 HTTP 服务没有授权头时必须返回 401。
