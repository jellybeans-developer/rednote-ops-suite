# 隐私说明

## 处理的数据

MCP 服务会在部署者指定的本地目录保存内容草稿、话题、素材本地路径、排期、审批状态、公开笔记 ID 和手工录入的运营指标，并追加不含正文的操作审计日志。

## 不处理的数据

本项目不要求也不应接收小红书密码、Cookie、短信验证码、设备指纹或私有接口签名。默认版本不抓取小红书页面。

## 数据控制

数据由 MCP 部署者控制，不会由本项目作者集中收集。删除部署目录中的数据文件即可删除本地数据；删除前请自行备份。远程托管者必须另行披露其存储位置、保留期、子处理者和删除方式。

## 安全

stdio 模式只与本机 MCP 客户端通信。HTTP 模式默认只绑定回环地址；绑定公网地址时强制要求长 Bearer Token。生产环境仍应使用 HTTPS、标准 OAuth、速率限制和隔离的持久化存储。
