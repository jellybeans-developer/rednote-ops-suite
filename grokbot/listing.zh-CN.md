# 小红书安全运营助手

把散乱的运营工作变成一条可审核、可追踪的本地内容流水线。

它可以帮助你：

- 梳理账号定位、受众和内容支柱
- 生成选题、标题、正文、话题和素材清单
- 检查绝对化宣传、医疗金融承诺和站外引流等常见风险
- 保存、读取、更新或取消本地草稿，并安排发布时间
- 按当前内容哈希组织逐条人工审核，再生成发布交接包
- 记录你在官方客户端完成的发布结果，并根据你录入的真实指标复盘

## 市场披露（审核必读）

- **非官方产品**：本 Bot 与小红书官方无隶属、授权或背书关系。
- **无私有接口**：不调用、不逆向、不封装未公开的小红书 API；默认版本不抓取小红书页面。
- **不收集登录凭据**：不索取也不应接收 Cookie、密码、短信验证码、设备指纹或私有签名。
- **受控发布默认开启**：Grok 插件中的可见浏览器流程默认可以登录、填稿和点击发布，但每条最终点击仍需要当前内容哈希、用户明确要求与固定确认短语。任何二维码、验证码或风控都必须由用户在官方页面处理。
- **批准短语不是真人认证**：固定确认短语 `I_APPROVE_PUBLICATION` 与 `contentHash` 只能把批准绑定到这一份内容。它不能证明点击者是人类；模型也可以调用 `approve_draft`。不要把它当作独立的真人授权边界。
- **素材哈希按文件字节计算**：路径存在时读取文件字节计入 SHA-256；缺失、非普通文件或不可读则失败，不会用路径字符串或空字节伪造哈希。
- **能力边界**：仓库已包含 Grok Build 原生 `.mcp.json`、`agents/`、`skills/` 与 `.grok-plugin/`，可直接从 GitHub 安装。进入 xAI 官方插件目录仍需通过 `xai-org/plugin-marketplace` PR 审核。
- **官方 OAuth ≠ 发笔记**：可选的 openaccount 设备授权脚手架默认关闭；启用后也只覆盖官方文档中的授权与 `min_user_info`，不能发笔记。注册官方应用是使用者自己的责任。

安全设计：不刷量，不绕过验证码或平台风控，不在没有逐稿批准和独立发布开关的情况下把内容推到小红书。

注意：平台规则会变化，预检结果不等于平台审核或法律意见。请以小红书现行规范为准。本目录是可复制的上架草稿，**不宣称**已核实 GrokBot 市场官方导入格式。
